Major Enhancements

Roll Dialog Extensions (Abilities / Active Effects)

A new extension interface for roll dialogs has been added. Abilities (and other mechanics) can now contribute additional roll actions via a small context menu (hamburger button) directly inside skill/spell/liturgy/ritual/ceremony roll dialogs.

This lays the foundation for adding special roll actions without having to fork or replace the core dialog. #2194

Active Effect Charges

Active Effects can now optionally have charges and be depleted when used. Depleted effects no longer apply. This is currently mostly for modifiers appearing in situational modifiers and postroll effects.

Depending on where the effect lives, depletion will either disable the effect (when embedded on an Item) or remove it (when embedded on an Actor). #2195

Post-Roll Improvements: Rerolls

Post-roll improvements gained a new option: rerolls.

  • Rerolls can be offered via Active Effects as a post-roll improvement.
  • Rerolls are exclusive (they cannot be combined with Fate Point / QS improvements).
  • Rerolls integrate with the existing “Begabung” reroll dialog and consume charges when applicable.

Improvements

  • Dodge modifiers: improved display of dodge modifiers (e.g. “Fixiert”).
  • Foreign spell malus: adjusted handling for Foreign-spell modifiers.
  • Pain immunity: for creatures immune to pain, the pain condition level is no longer preselected in checks.
  • Personae Dramatis: required fields are now marked more clearly.
  • Game manual: a bunch of additional chapters are now available in the game manual, especially for the English version (screenshots will follow later, we have to create around 190 more… uff). Currently only in the wiki, ingame journals will be updated after the creation of the screenshots.
  • Personae Dramatis: search now also matches persona tags.
  • Ranged combat: added an Aim button that sends a chat message and tracks aiming progress (1/2, 2/2).
