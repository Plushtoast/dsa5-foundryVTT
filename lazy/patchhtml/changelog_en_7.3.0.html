Major Enhancements

Personae System

A comprehensive character relationship and social contact system has been implemented. This new system allows you to:

  • Create and manage social contacts with detailed relationship information
  • Track relationship levels and social standings with NPCs
  • Organize contacts in a dedicated interface with drag-and-drop functionality
  • Enhanced character interaction mechanics for social encounters

This system expands the social aspects of gameplay and provides better tools for managing complex character relationships in your campaigns.

You will find this feature in the new calendar section. The main intention is to build a library for players, so they can look-up already encountered creatures, enemies and friends.
The interface supports searching and grouping by factions as well as entering custom personal notes. Encourage your players to add info to these sections so they can remember important details even after long playing pauses.
You can add new entries to the Personae Dramatis section via Journals. Create new journals and add "Personae Dramatis" pages. These pages act as a proxy to real actor documents. In this way you can add or mask additional information to the entries. E.g. giving them faction groups or renaming because their real identity is still hidden.
The easiest way is to drag and drop actors onto the "Personae Dramatis" page. This will prefill certain values. Please note that the page name will be the default faction for persons, while for beasts it will be their creature type.
You can show and hide single entries with ease, so you can prepare important actors and reveal them to the players during the adventure.

Also note that the social standing (relationship level) is currently not automated on any automatic modifiers.

Calendar System Improvements

The calendar system has received significant enhancements:

  • Infinite Scroll: Navigate through months seamlessly with endless scrolling functionality
  • Browse Mode: Browse calendar dates without accidentally changing the current game time #2053
  • Today Marker: Clear visual indication of the current date
  • Improved Navigation: Better month scrolling and navigation controls
  • Holiday Enhancements: Improved holiday system with better caching and performance

Hotbar Redesign

The hotbar system has been completely redesigned for better usability:

  • Responsive Design: Hotbar now adapts to different screen sizes
  • Enhanced Customization: Improved macro customization capabilities #1782. You can resort elements within the bar
  • Better Performance: Optimized rendering and interaction
  • Modern Interface: Updated visual design
  • Improved tooltips: More details on plenty of things e.g. character overview
  • Advanced weapon handling: A entire new section showing the currently equipped weapons. By rightclick on the weapons you will have a lot of options for equipping and unequipping weapons. These options will enforce that you can only equip as much as fits in two hands. So no Two-handed sword and two-handed hammer at the same time anymore (unless wielded in one hand). This properly helps in setting up automated modifiers for e.g. weapon size.

Please note that the hotbar replacement setting must be activated for this feature.

Improvements

  • Trap Enhancements: Traps can now be manually disarmed with improved state management and interaction mechanics
  • Status Effect Automation: The "Stumm" (Mute) status effect now automatically applies spell casting modifiers #2044
  • Trader Interface: Categories with no items are now hidden in trader interfaces for a cleaner experience #1834
  • Item Library Performance: Improved performance for large worlds when using detail filters in the item library #2057
  • Blessing Macros: Added macro field support for blessings (Segnungen) #2063
  • Skill Roll Improvements: You can now roll on a group category on the character sheet (e.g. body group skills) #1624
  • Wound Treatment: Improved wound treatment (Wundbehandlung) system macro
  • Audio Enhancements: Added grip sound effects for better immersion (swapping weapons, requires game audio bundle)
  • The status effects tab on an actor sheet has new details and improvements.
  • Wero999 has joined the list of contributors with providing macros for some abilities and spells
