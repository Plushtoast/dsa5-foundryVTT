News (26/06/2025)

TDE-Foundry 13: The Biggest Update Since Launch

After more than six months of development, the time has come:
The TDE system for Foundry has been thoroughly modernized and completely migrated to Foundry's new AppV2 framework. This massive overhaul was necessary to enable future features, expansions, and a stable system foundation.

Feedback & Bug Reports

Found a bug? Have an idea for a new feature or improvement?
Help us make the system better by posting your feedback directly on GitHub!

Use the GitHub Issue Tracker to:

  • Report bugs and technical problems
  • Suggest features or improvements
  • Ask for clarification on existing mechanics

Please include as much detail as possible — screenshots, error messages, and steps to reproduce are especially helpful.

Every report helps us improve the world of Aventuria. Thank you!

On Our Own Behalf

Foundry updates are often destructive and involve a tremendous development effort. A simultaneous system release with a new Foundry version is therefore rather the exception – even in this case, a release would have made more sense months later.

The adjustments, testing, and necessary changes require a lot of time and resources – so in the future, patience will be needed more rather than less.
