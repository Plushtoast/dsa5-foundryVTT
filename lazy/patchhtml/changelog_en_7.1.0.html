Important improvements (26/05/2025)

Appv2 & Refactors

The system has been updated to Foundry's new framework, AppV2. This modernized architecture introduces a range of advanced features that enhance performance, maintainability, and responsive design. However, implementing these improvements required an extensive refactor that has already been underway for over six months.

Despite the scale of the changes, you should only notice subtle differences in the overall user experience of the DSA/TDE system. Most changes took place under the hood and remain invisible to the end user. In the process, many features were refined or completely rewritten to improve usability and consistency.

Data Models

With this version, DSA/TDE transitions from using templates to a system of Data Models. These models enforce stricter input validation—for example, you can no longer enter text into numeric fields. The primary benefit is a reduction in input errors and more consistent access to item and actor data.

That said, this change can potentially strip invalid or legacy data from existing elements in your world. We've conducted extensive testing, but some edge cases may remain. If you notice any issues, please report them.

Special thanks to everyone who contributed their worlds for testing—your help was invaluable.

World Destroyer

Several underlying changes in Foundry have broken compatibility with older content—especially macros. Please remove outdated DSA macros and replace them with the updated versions found in the compendiums.

To ensure your actors are fully compatible with the new system, we recommend using the World Destroyer utility, included in the core module and available via the settings menu.

Ingame calendar

Foundry VTT 13 now provides basic calendar support, which is now integrated into the system. A lightweight version of the TDE calendar is included by default (and can be disabled in settings). While simple for now, it opens up possibilities for future features such as automated artifact recharging.
Optionally you can also enable the automatic daylight adjustment depending on the current time and add some additional light during the night depending on the phase of the moon.

More detailed calendars will be included in regional supplements—for example, Thorwal will feature its own calendar with corresponding month and day names.
The calendar depiction is highly optimized with hardware acceleration and additional information about the gods of the respective month ready for your players.
It features seasons, months, weekdays, moon phases and holidays.

Style

Foundry V13 significantly disrupted the layout of the TDE system. In response, we’ve rebuilt and adjusted nearly every UI component.

At this time, we only support one theme combination: light-theme + dsa5immersive. Other theme combinations are not supported.

The character sheet remains a work in progress and will continue to receive updates.

Dynamic Tokens

All tokens in official premium modules will soon be updated to support Dynamic Tokens. These tokens allow for animated effects (such as health loss) and customizable token rings.

The dynamic DSA/TDE token is already included in the system and will be enabled by default.

A huge thank-you to Twolli, who is creating these tokens on a voluntary basis. This feature would not be possible without his incredible contribution—thousands of tokens are already available across the premium modules.

Token Rotation & Flanking Detection in Foundry13

By default, Foundry13 enables automatic token rotation when tokens move. While this might feel unfamiliar at first, it offers several gameplay advantages:

  • Automatic Flanking Detection: Defense rolls can automatically determine whether an attacker is positioned behind a defender and apply the appropriate modifier.
  • Integration with Dere Position System: This system—also enabled by default—can apply additional modifiers based on movement and range.

You can customize or disable this behavior:

  • Token Rotation: Toggle automatic rotation in Foundry’s core settings.
  • "Attack from Behind" Angle: Configure this in the Master’s Menu. The default is 120°, which defines the rear cone behind a defender. Setting it to 0° disables the detection entirely.

Quick Tip:

  • Hold Shift + mouse wheel to rotate a token.
  • Hold Ctrl + mouse wheel for fine rotation steps.
