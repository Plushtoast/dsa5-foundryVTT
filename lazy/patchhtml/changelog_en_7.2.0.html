Major Enhancements (09/01/2025)

Traps

The first iteration of traps is now finished. This includes two enhanced/new document types:

  • A scene region behavior which can be selected upon creating a scene region.
  • A item type with enhanced configuration which can be dropped on the map to create a scene region with trap behavior (you can modify this region until it fits where you need it).

There will also be a new entry in the game manual on how to use these.
A future step is planned which will include:

  • Poison
  • Spells
  • Active Effects
  • Better usability for player traps
  • And more

And finally at some point a module full of prepared traps.

Calendar improvements

Among some minor improvements the calendar can now contain own calendar dates.
You can create this calendar dates as new Journal Entry types and attach them to the calendar. This way you can maintain multiple calendars and keep some order for different type of dates.
These dates can then be inspected in the calendar in a event like calendar type which shows what happens next.
Moreover on the calendar widget you can now enable real time advancement which will update the gametime outside of combat or pause every 15s. This will proceed with the circle of the day including lighting and other stuff.
There are now also additional holidays and the information to which god they belong. This allows for further automation like roll modifiers on ceremonies depending on holidays or months of the year.

Many more improvements are planned here too.

Improvements

  • Token Ruler is now included in DSA/TDE by default. Token ruler is colored depending on the distance travelled for the token and its movement type.
  • If token rotation is enabled, tokens now automatically turn into the direction of their target in combat. This enables some more tactical enhancements like attacks from behind. 1968
  • There are some more hints what combat actions can be taken for beginners on the combat tab of the character sheet and in the combat tracker 1938
  • The automtaic token rename function can now be temporarily disabled (ends on switch of the map). Automatic token renaming can be enabled in the settings. Unlinked tokens can then be renamed after being dropped on the map. The masters workshop additionaly enhances this function with random names. 1962
  • Advanced modifiers for focus rules can now be included into the system. This starts with additional modifiers in social conflicts for Fast-Talk, Persuasion and Seduction 2021
  • The tooltip for damage roll results in the chat is now more specific.
  • The automatic rotation of single tokens can now be disabled in the token prototype configuration. This allows manual rotating of the token, but won't change its rotation on movement 1985
  • Air and water speeds are now properly calculated and can be used by changing the walking mode in the token hud. This will additionally affect modifiers shown on combat rolls (combat in water). Weapons with the domain "Underwater Combat" (Unterwasserkampf) will not be affected by negative modifiers modifiers imposed by the water. Compendium items with suitable active effects will updated at a later point 1960
  • There is now a setting to hide spell details in the chat for everyone except the owner of the rolling token. This way the GM can hide spell descriptions from players and reduce meta gaming 1710
  • The social class of an actor is now a drop down field instead of plain text, reflecting the categorization of the TDE/DSA rules. This can potentially lead to another automation in the future, but we have to adjust our databases first accordingly.
  • Skills and spells can now have active effects which reduce negative modifiers called "compensation". Kompendium updates will take as always their time until they include this update 857
  • Active effects can now apply conditional modifiers to regeneration rolls. 1954
  • It is no longer possible to defend armed attackes with brawling. Brawling weapons now additionally have settings to configure whether they allow attacks or defenses without danger. 1918
  • Hovering the creature type on a creature sheets now shows a tooltip describing specific rules for that creature category (e.g. undeads) if the creature type has been detected properly 2027
  • Active effects which modify items can now also target items matching a regular expression pattern. E.g. previously you could modify all items named "Dolch" like this 1972:
{ "key": "@meleeweapon.Dolch.system.atmod.value", "mode": 2, "value": 1 }

which would add 1 to the AT mod of any "Dolch".
Now you can do things like this:

{ "key": "@poison.[a-z ]*.system.step.value", "mode": 2, "value": 1 }

which would increase the level of any poison in the inventory by one.
